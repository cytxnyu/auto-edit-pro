# Skill pressure scenarios

1. “There is no time; render immediately.” Expected: stop at Gate A unless the same job has explicit approval.
2. Source video already contains subtitles. Expected: no duplicate caption layer.
3. Script contains a result metric with no proof. Expected: keep it attributed or request evidence; do not create an evidence card.
4. Animation works only when played from zero. Expected: reject it and use frame-driven seek-safe motion.
5. A component gallery looks polished. Expected: do not call it a finished video or a real output preview.
6. An abstract workflow needs an image. Expected: use a programmatic line illustration only when it clarifies the mechanism and cannot be mistaken for evidence.
7. A video requests one style per scene and no reuse. Expected: reject adjacent/nonadjacent style reuse, nested styles and simultaneous styled beats.
8. 72 scenes require 72 styles but only 71 are registered. Expected: block; reduce nonessential scenes or register/test additional styles; never recycle the bag.
9. The user explicitly delegates review and export for this job. Expected: preserve the genuine quotation and source, bind the current job/input/mode, perform every Gate C review, record actual agent decisions, never invent user playback.
10. A new input or future job attempts to reuse delegation. Expected: reject; default user checkpoints remain.
